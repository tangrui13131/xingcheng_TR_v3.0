================================================================================
                  4-安装配置说明 —— 部署安装与运行配置文件
================================================================================

本目录包含"星辰健康管理系统"的全部部署脚本、环境配置和构建配置文件。

--------------------------------------------------------------------------------
一、部署脚本（deploy/）
--------------------------------------------------------------------------------

deploy/
├── build-all.bat            一键编译打包脚本（Maven + npm）
├── deploy.sh                Linux 部署脚本（完整部署流程）
├── deploy-upgrade.sh        Linux 增量升级脚本
├── start.bat                Windows 服务启动脚本
├── stop.bat                 Windows 服务停止脚本
├── nginx.conf               Nginx 反向代理配置
│                             - 前端静态资源代理
│                             - API /prod-api/ 代理到后端 8080 端口
│                             - WebSocket 代理
├── installer.iss            Inno Setup 安装包脚本（Windows安装程序）
├── xingchen-admin.jar       后端 Spring Boot 可执行JAR包（已编译）
├── xingchen-deploy.zip      部署包压缩档案
├── admin-ui/                管理后台前端编译产物（Vue3 dist）
├── user-ui/                 用户端前端编译产物（Vue dist）
└── sql/                     部署用SQL脚本（与3-数据库脚本内容一致）

--------------------------------------------------------------------------------
二、环境变量配置（.env.*）
--------------------------------------------------------------------------------

.env.development              开发环境
  - VITE_APP_BASE_API = '/dev-api'       后端API前缀
  - 调试模式、SourceMap等

.env.production               生产环境
  - VITE_APP_BASE_API = '/prod-api'      后端API前缀
  - 压缩、优化开启

.env.staging                  预发布/测试环境
  - VITE_APP_BASE_API = '/stage-api'     后端API前缀

--------------------------------------------------------------------------------
三、项目构建配置
--------------------------------------------------------------------------------

package-admin.json           管理后台（XingChen-Vue3）npm依赖
  - Vue3 / Element Plus / Pinia / Axios / ECharts 等
  - 开发/构建/预览脚本

package-user.json            用户端（xingchen-ui-user）npm依赖
  - Vue3 / Vant4（移动端UI）/ Axios 等

vite.config.js               管理后台 Vite 构建配置
  - 代理配置（开发时API转发）
  - 路径别名 @ → src
  - 插件：压缩/SVG图标/自动导入

vite-user.config.js          用户端 Vite 构建配置
  - 代理配置
  - Vant4按需导入
  - 端口：81

index.html                   管理后台入口HTML
index-user.html              用户端入口HTML

--------------------------------------------------------------------------------
四、运行配置
--------------------------------------------------------------------------------

my.ini                        MySQL数据库配置文件
  - 端口：3306
  - 字符集：utf8mb4

一键启动.bat                  项目总启动脚本（后端+数据库+前端）
一键启动-管理后台.bat         仅启动管理后台前端
一键停止.bat                  停止所有服务
启动管理后台前端.bat          启动管理后台开发服务器

--------------------------------------------------------------------------------
五、快速启动步骤
--------------------------------------------------------------------------------

1. 安装环境
   - JDK 8+（推荐JDK 11）
   - MySQL 5.7+
   - Node.js 16+
   - Maven 3.6+

2. 初始化数据库
   - 执行 3-数据库脚本/ry_20260321.sql
   - 执行 3-数据库脚本/quartz.sql

3. 启动后端
   - 运行 deploy/start.bat
   - 或直接运行 java -jar deploy/xingchen-admin.jar

4. 启动前端
   - 管理后台：运行 启动管理后台前端.bat
   - 用户端：  运行 一键启动.bat

5. 访问系统
   - 管理后台：http://localhost:80
   - 用户端：  http://localhost:81
   - 默认账号：admin / admin123
